你是 Windows 内网机器上的安装助手。请帮我把"重型燃机集成设计平台"离线安装包装好并启动成功，全程不得访问互联网，只能用本地文件。

【材料】
- 安装包：ai_platform_offline_win64.zip（即本文件所在目录整体压缩而成；如尚未解压，先右键解压或用 PowerShell Expand-Archive 解压到本地某个目录，以下称 <包目录>，本提示词就放在 <包目录> 根下）
- 包内结构：<包目录>/app（后端源码）、alembic（数据库迁移脚本，0001~0004）、alembic.ini、frontend/dist（前端页面）、wheels（全部依赖 wheel，支持 Python 3.10~3.13 的 Windows 64 位）、requirements.txt（锁定版本清单）、install.bat（一键安装）、start.bat（一键启动）、README-离线部署.md（部署说明，可先读一遍）

【硬性约束】
1. 机器无外网，所有依赖必须用包内 wheels 离线安装（pip 加 --no-index --find-links wheels），禁止 pip install 在线拉包。
2. Python 版本必须是 3.10 ~ 3.13（64 位）。3.14 或 32 位会因缺少对应 wheel 而失败。
3. 数据库为 SQLite（包目录下的 ai_platform.db），无需装数据库软件；如果是老版本升级安装，alembic upgrade head 会自动迁移历史数据，不要手工改库。

【安装步骤】
1. 环境检查：运行 `py -3 --version` 或 `python --version`，确认是 3.10~3.13 且 64 位；没有就去内网软件源装一个，装完重开终端。
2. 在 cmd 中进入 <包目录>，运行 install.bat。它会依次：创建 .venv 虚拟环境 → 从 wheels 离线装依赖（fastapi/uvicorn/sqlalchemy/aiosqlite/alembic/asyncpg/pydantic）→ 执行 alembic upgrade head 初始化数据库（首次生成 ai_platform.db）。
3. 每步如果报错，先看报错原文：依赖失败通常是 Python 版本不对或 wheels 目录被移动；数据库失败把完整报错贴出来分析，不要盲目删库。
4. 安装成功后运行 start.bat，它会启动 uvicorn（0.0.0.0:8000）并在 3 秒后自动打开浏览器。
5. 验收（三条都要过）：
   a) 命令行 `curl http://127.0.0.1:8000/api/health` 返回 {"status":"ok"}；
   b) 浏览器打开 http://127.0.0.1:8000/ 能看到"重型燃气轮机集成设计平台"页面，"设计算例管理/CFD 任务监控/代理模型管理/智能体运行记录"四个菜单都能点开；
   c) 在"代理模型管理"页对模型"效率线性代理"点"预测"，输入 [1.0, 2.0]，应返回输出 [3.3]（说明推理接口正常；若新装的库没有该模型，先在页面新建一个：状态=可用，内嵌权重填 {"type":"linear","coef":[1.2,0.8],"intercept":0.5}）。
6. 如果其他内网机器也要访问，确认 Windows 防火墙放行 8000 端口（netsh advfirewall firewall add rule ... 或图形界面），访问地址用 http://<本机IP>:8000。

【常见问题处理】
- 提示"未找到 Python"：安装 3.10~3.13 后重跑 install.bat；
- 提示 pip 找不到包/版本不符：确认在 <包目录> 里执行、wheels 目录完整、Python 是 3.10~3.13 的 64 位；
- 8000 端口被占用：用 `netstat -ano | findstr :8000` 找到占用进程，可停掉它，或把 start.bat 里的 --port 8000 改成其他端口；
- 页面 404 "frontend not built"：说明 frontend/dist 丢失，重新解压完整安装包；
- 启动即闪退：用 cmd 手动执行 `.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000` 看完整报错。

完成后请汇报：Python 版本、安装与迁移是否成功、健康检查/页面/预测三项验收结果，以及遗留问题。
